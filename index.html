다른 네트워크 주소 선택:
1
LTE / 5G / Wi-Fi 어디서나 즉시 접속

외부 접속 터널 주소(https://...lhr.life)가 자동 생성되어, 공유기 설정이나 Wi-Fi 연결 없이도 휴대폰 카메라로 QR만 찍으면 바로 열립니다.

2
앱처럼 홈 화면에 추가하기

모바일 브라우저 메뉴에서 [홈 화면에 추가]를 누르면 언제든 전체화면 앱처럼 사용할 수 있습니다.
